# Tapenade set01 `lh008`

`lh008` is a dependency-free fixed-form regression with a local state value
that is incremented between two products:

```text
x = 10.5*y
z = 11.5*y
```

The port keeps the final in-place `y = 0` write and adds the scalar
`objective = x + 0.5*z` so reverse mode has one useful dependent. The runner
compiles every unmodified upstream source, generates FortAD JVP/VJP code, and
checks both modes against hand derivatives, a four-step central-difference
sweep, and the JVP/VJP adjoint identity.

Run it after fetching the pinned Tapenade checkout:

```sh
FORTAD_REPO=../fortad TAPENADE_REPO=upstream/tapenade \
  scripts/bench_tapenade_set01_lh008.sh
```
