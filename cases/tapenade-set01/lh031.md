# Tapenade set01 `lh031`

The exact pinned source is a short fixed-form subroutine that updates `x`,
then `y`, then `z`, with the intermediate expression `sin(x)` represented by
the typed external function `dpf1`. Its stored tangent, reverse, and
multidirectional references all compile with strict Fortran 2018 flags. The
multidirectional reference requires the pinned
`nonRegressions/DIFFSIZES.f` include, which is supplied by the runner.

Fresh parser, tangent, and reverse files are generated with Tapenade commit
`e59864cab441d4175df75383b3ff58c3dcd26df9` and strictly compiled. FortAD at
`db0050259520b618e2a0aeba203c85a7613943b5` refuses the exact source in both
modes at its legacy `RETURN` statement (line 9). That refusal is preserved as
evidence; the runner does not claim exact-source support.

The bounded standard-conforming port exposes the overwritten values as
`x_out`, `y_out`, and `z_out`, preserving the exact dataflow. FortAD generates
one JVP and one reverse derivative for each scalar output. An independent
closed-form hand derivative, central-difference sweep, and adjoint identity
check the generated code at a finite test point. The port is a numerical
oracle boundary, not a replacement claim for arbitrary legacy fixed-form
sources.
