# Tapenade set01 `lh007`: exact COMMON-block refusal

`lh007` is a valid fixed-form source under the strict compiler gate, and the
pinned Tapenade checkout regenerates parser, tangent, and reverse sources that
also compile strictly. FortAD currently reaches a stable boundary at the
first `COMMON /cc/` declaration (`line 6`) in both exact-source modes. This
case is therefore recorded as an expected refusal; it is not an exact-source
support claim.

The source also passes the scalar actual `x(5)` to the explicit-shape dummy
`y2(0:6)`, and reads `y2(3)` and `y2(5)`. The bounded port
[`lh007.f90`](lh007.f90) makes the corresponding contiguous-storage
observations `x(8)` and `x(10)` explicit. It exposes `u` and `v` as initialized
inputs because the exact source reads those local variables before assignment;
the resulting standard-conforming routine is used only as an independent
algebraic oracle.

The runner checks all four exact/stored upstream sources, fresh pinned
Tapenade parser/tangent/reverse generation and strict compilation, the exact
FortAD diagnostic, and FortAD JVP/VJP compilation of the normalized port. The
independent harness checks hand JVP/VJP values, a three-step central-difference
sweep, and the VJP/JVP adjoint identity.

Run it with the requested baselines:

```sh
FORTAD_REPO=../fortad TAPENADE_REPO=upstream/tapenade \
  scripts/bench_tapenade_set01_lh007.sh
```
