# Tapenade set01 `lh020`

The pinned source is fixed-form Fortran with an alternate-return argument. For
every `n >= 1`, its first loop iteration multiplies `x(1)` by `y(1)`, jumps
over the remaining body, and exits through `return 1`. The `y(i)` update is
therefore unreachable. The stored `program_d.f` and `program_b.f` references
record the same active path.

FortAD does not accept an alternate `RETURN` inside a loop, and a direct
in-place array-output reverse probe produces an invalid duplicate adjoint
declaration. The bounded standard-conforming port exposes the exact active
observation as scalar `x1_out`, retains the input arrays, and makes the
alternate-return branch explicit as integer `branch`. Its contract is
`n >= 1` with actual arrays large enough for `n`; this preserves the upstream
first-element result and its derivative while avoiding an unsupported legacy
control-flow/interface shape.

The independent harness supplies a hand JVP/VJP, two positive trip-count
cases, a four-step central-difference sweep, branch-status checks, and the
JVP/VJP adjoint identity. The runner also compiles the exact upstream source
and stored references, regenerates fresh pinned Tapenade parser/tangent/reverse
files, strictly compiles those outputs, and compiles and runs both FortAD
modes for the bounded port.

Run locally:

```sh
FORTAD_REPO=../fortad TAPENADE_REPO=upstream/tapenade \
  scripts/bench_tapenade_set01_lh020.sh
```
