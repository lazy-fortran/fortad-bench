# Tapenade set01 `lh029`

The pinned upstream case is fixed-form Fortran with three routines. `s1`
calls `s3` on the incoming array, fills a local 100-element `V`, calls `s2`
on that array, and returns `xx = x1 + x2` while `z` is transformed twice by
`z = 3/z`. The exact primal, stored tangent, stored reverse, and stored
multidirectional reference all compile strictly when Tapenade's checked-in
`nonRegressions/DIFFSIZES.f` is supplied as `DIFFSIZES.inc`.

Fresh pinned Tapenade parser, tangent, and reverse generation also produces
strictly compilable files. FortAD's exact-source forward and reverse probes
both stop at the same call-boundary diagnostic: `s2` may write its actual
arguments, so the current inliner requires plain variables.

The case therefore includes a deliberately bounded standard-conforming port.
It fixes the array length at seven elements, keeps the two reciprocal `z`
updates and the 100-term local sum, and unrolls those bounded computations so
the pinned FortAD transform has no legacy call-boundary or loop-coefficient
ambiguity. Independent hand JVP/VJP code, central differences, and the
adjoint identity validate the port and both generated reverse objectives
(`xx` and `z_out`). This is bounded evidence, not an exact-source support
claim.

Run the reproducible probe with:

```sh
FORTAD_REPO=../fortad TAPENADE_REPO=upstream/tapenade \
  scripts/bench_tapenade_set01_lh029.sh
```

The resulting evidence is recorded in
[`results/tapenade_set01_lh029_validation.txt`](../../results/tapenade_set01_lh029_validation.txt).
